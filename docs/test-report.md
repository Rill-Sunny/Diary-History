## 2026-11-11 本地运行故障修复

用户截图中的 `http://127.0.0.1:5173` 使用了新前端，但 8080 后端仍是 10:18 启动的旧进程，早于 10:56 的新版 JAR。修复前，用独立测试账号登录后，`/api/stats/coverage`、`/api/data/exportable`、`/api/settings/avatar` 均返回 HTTP 404；`/api/stats/activity` 和 `/api/shares` 返回 200。分享和数据页都依赖 `exportable`，所以与日历同时报错。原请求层把无 `message` 的错误统一显示为“操作未完成，请稍后重试”。

本地数据库的 Flyway 版本仍为 V1，`app_users` 中没有 `avatar_png`。先备份本项目数据库至被 Git 忽略的 `var/maintenance/before-runtime-fix-20261111.sql`，再重启新版后端。V3、V4、V5、V6 迁移全部成功。

在实际 5173 网站上，使用临时测试账号执行 Chrome 无头浏览器回归：

- 登录并创建一篇日记，日历、分享选择框和数据导出列表均显示该日记，无错误提示。
- 提交分享申请，列表显示“等待审核”。
- 通过文件选择框上传 PNG，服务返回 160 × 160 头像，设置页和侧栏显示图像；刷新后仍显示。
- 3 MiB 文件在请求前被拒绝，并在头像旁显示大小限制；重新选择同一有效 PNG 可成功上传。
- 移除头像成功，无浏览器运行时错误。测试账号及关联数据已清理。

设置页已加入格式、尺寸和大小说明，以及上传状态、失败原因和同文件重试。API 请求层回归覆盖非 JSON 错误、伪成功响应、正常 JSON、冲突详情、CSRF 和 204；在 `frontend` 运行 `node --test tests/api.test.mjs`，三组通过。前端类型检查及生产构建通过。

## 2026-11-11 Markdown 文件读取与预览修复

普通 UTF-8 文档经真实文件选择按钮可正常预览。另复现了 GB18030 和 UTF-16 文档的问题：原 `.md` 读取固定按 UTF-8 解码，中文变成乱码；ZIP 内文档使用严格 UTF-8 解码，直接抛错。导入错误原先仅显示在页面顶部，滚动至文件选择位置时不易发现。

`.md` 与 ZIP 内 Markdown 现共用解码流程，支持 UTF-8、GB18030、UTF-16 LE/BE。无法读取的文本和损坏 ZIP 返回中文提示，错误显示在文件选择按钮旁。页面增加读取状态、无日期文档的日期选择说明和局部导入成功提示，重新选择文件时清除旧预览。解析器同时保留首行代码缩进，识别含空格或全角数字的中文日期，并正确解析带括号的图片文件名。

通过实际 `127.0.0.1:5173` 页面选择文件、预览并确认，UTF-8 多日期文档导入 2 篇、GB18030 文档导入 1 篇、UTF-16 ZIP 导入 1 篇、无日期文档手动指定日期后导入 1 篇、无年份文档指定年份后导入 2 篇。读取后端确认共 7 篇，中文内容保持完整；重复导入 UTF-8 文件跳过 2 篇。损坏文件局部报错，同名文件重选后可预览，空文件显示原因，无浏览器运行时异常。临时测试账号及数据已清理。

`node --test frontend/tests/markdown-import.test.mjs frontend/tests/api.test.mjs` 共 8 组通过，前端类型检查和生产构建通过。结果见 [导入检查结果](screenshots/markdown-import-checks.json) 和 [导入预览截图](screenshots/markdown-import-fixed.png)。

## 2026-11-11 导入检查按钮修复

原“检查重复并预览”按钮由所有导入条件共同控制禁用状态。缺少年份、缺图、前言未处理或跨年未确认时，用户无法点击，也无法在按钮附近看到完整原因。现仅在任务进行中禁用；点击后先校验，在按钮上方列出待处理事项，提供“前往处理”跳转到相关输入框。校验通过才调用预览接口。

默认年份改为只更新尚未手填的日期，不再重建整份预览。实际 5173 浏览器验证了缺年、缺图、纯图片转纯文字、全跳过、前言、跨年、无效及未来日期；无效输入不会发送预览请求。修改默认年份后，手填日期、标题、目标日记本、跳过及其他选项均保留。补齐条件后实际导入 2 篇；逐篇手填日期无需另设默认年份。无浏览器异常，类型检查及生产构建通过。临时测试账号和关联数据已清理。结果见 [检查按钮回归](screenshots/import-button-checks.json) 与 [校验提示截图](screenshots/import-button-validation.png)。

## 行为与响应式

- 年份切换显示该年真实活动。默认今年；年份选项来自实际数据。热力图聚焦/点选显示具体日期和活动次数，不把活动日冒充日记日期。
- 连续天数按真实写作活动；今天无活动但昨天有活动时保留连续，并显示明确说明。过滤未来日期与无效计数。
- 月历切月同步选择本月首日（当月选择今天）；回到今天同步月份与日期。日记加载使用独立请求序号防止旧响应覆盖，错误可重试，支持单日分页。
- 桌面按概念原尺寸验收。窄屏上半区堆叠，热力图局部横向滚动并可键盘查看；本周与月历保持可读，日记列表移至月历下方。不让整个页面横向溢出。
- 暗色采用现有炭灰/浅蓝，沿用相同构图。加载、空数据、API错误显示真实状态。

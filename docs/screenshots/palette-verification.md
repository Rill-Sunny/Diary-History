# 蓝灰配色复验

2026-11-11。按用户最新要求，将偏绿纸面与橄榄绿操作色替换为经典蓝、中性灰和白色。配色参考 [IBM Carbon 官方说明](https://www.carbondesignsystem.com/building-blocks/foundations/color/overview)。

## 修改范围

- 浅色：白色写作区、中性灰导航、蓝色主操作；深色：炭灰纸面、深灰导航、浅蓝操作色。
- 统一按钮、导航、日历、设置色板、焦点、选择区域、弹窗遮罩、新标签默认颜色与导出 HTML 的配色。
- 设置提供经典蓝与玫瑰红。旧账号和备份的 olive 在前端归一化为 blue，服务端接口保持兼容。
- 保存时间不再降低文字透明度；选中日期的篇数使用不透明文字；悬停选中日期保留强调色背景。

## 验证结果

使用本机 Edge 隔离浏览器、真实 Java API 与已有前端验收账号。没有写入日记、保存设置或改变服务端偏好。

- 已确认服务端旧值 olive 在页面显示为 blue，设置默认选中经典蓝。
- 第一轮完整快照覆盖 1440 × 1000 与 390 × 844 的写作、日历、全部日记、日记本、数据管理与设置，以及玫瑰红切换，保存 28 张 palette- 前缀截图。该轮无页面错误、横向溢出或业务写入请求。
- 蓝色主按钮实测对比度：浅色正常 5.00、悬停 7.79；深色正常 10.62、悬停 13.79。次要文字、选中导航和可测的日历选中日期通过 4.5:1 要求。
- 第一轮导航对比度解析未识别浏览器的 color(srgb ...) 格式，修正解析后实测浅色 6.35、深色 11.83。此为验证脚本修正，非产品颜色修正。
- 验收账号没有日记，因此选中日期的篇数没有实际内容可截图；对应 CSS 已核对 opacity 为 1，且继承选中日期文字颜色。
- 已人工查看浅深写作页与手机设置页，蓝色操作与正文层级清楚。

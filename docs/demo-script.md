# 演示脚本（约 7 分 30 秒）

## 演示前准备

- 使用隔离 MySQL 库和虚构管理员账号；不要录入或展示真实私人日记。
- 准备一篇虚构日记，例如“雨后校园散步”，配一张可公开展示的自制/许可图片；准备一个本子和两个标签。
- 准备一篇测试日记进入审核队列；若尚未完成 SMTP 环境，则不要现场演示邮箱注册。
- 启动后端、前端，检查浏览器登录与图片路径。确认数据库备份和媒体目录均为演示数据。
- 若无隔离数据库、管理员账号或分享快照审核成功路径，跳过相应环节并说明原因。

## 流程

| 时间 | 操作 | 讲述重点 |
|---|---|---|
| 0:00–0:40 | 打开登录页并介绍留白日记 | 目标是私人长期记录，所有日记默认私密。 |
| 0:40–1:20 | 进入主界面，切换浅/深色和强调色 | 说明统一 token 与桌面/窄屏布局。 |
| 1:20–2:50 | 创建当天日记，输入标题和正文，使用标题/列表/引用格式，添加虚构图片和描述 | 展示 Tiptap JSON、自动保存状态、日记本与标签。 |
| 2:50–3:40 | 在首页查看当天的世界事件，再打开往年同日和日历 | 展示事件的原始来源，区分写作活动日期和日记覆盖日期。 |
| 3:40–4:50 | 提交一篇测试日记分享申请，登录管理员审核快照，再以普通账号阅读链接 | 强调审批内容是固定版本，私人后续编辑不会改变公开快照。若当前环境无法完整验证则只讲设计，不伪造结果。 |
| 4:50–5:40 | 打开数据页查看 Markdown 导入和完整备份入口 | 解释追加恢复、批次去重与离线 HTML。不要把未验证的复杂 ZIP 边界描述为已通过。 |
| 5:40–6:20 | 删除一篇虚构日记并在回收站恢复 | 说明超过 15 天清理和图片引用清理策略。 |
| 6:20–7:10 | 展示架构图和关键代码路径 | Vue/API、Spring Service/MyBatis、MySQL/Flyway 与用户隔离媒体目录。 |
| 7:10–7:30 | 总结已实现和外部依赖 | 说明事件资料随前端发布，通知送达依赖配置和设备。 |

## 备用方式

如果演示环境缺少 SMTP 或 Web Push 配置，展示设置中的服务状态。历史事件可直接使用随前端发布的资料。如果数据库尚未准备好，使用架构图和隔离环境中获取的截图讲解。
